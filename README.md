# Anime Stylized Rendering System

Research project for developing a modular real-time stylized rendering system for anime-style 3D graphics.

---

## Goal

This project explores how to build a flexible rendering framework for stylized real-time graphics rather than reproducing a single visual style.

The primary objective is to design a rendering system that allows artists and technical artists to freely control lighting, shadows, materials, and post-processing while maintaining real-time performance.

---

## Motivation

Modern anime games rely on much more than traditional toon shading.
Stylized rendering combines custom lighting models, material-specific shading, rendering pipelines, and post-processing to achieve expressive visuals.

Instead of treating rendering as a fixed lighting model, this research investigates rendering as an artist-controllable system that supports multiple illustration styles.
